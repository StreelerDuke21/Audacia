# Audacia

Proyectos desarrollados durante prácticas profesionales en AudacIA.

Cada proyecto está en una carpeta independiente y contiene:
- **Código** (carpeta `codigo/`)
- **Instrucciones de uso** (`README.md`)
- **Requirements** (`requirements.txt`)

## Proyectos

| Proyecto | Descripción |
|----------|--------------|
| [Bird_Flight](./Bird_Flight/) | Juego web 3D controlado por body tracking (cámara + MoveNet + Three.js). El jugador controla un halcón con gestos. |
| [Ball_on_Plate](./Ball_on_Plate/) | Control inteligente Ball-on-Plate con Reinforcement Learning (SAC), simulación Gymnasium, visión por computador (OpenCV) y control de servomotores. |

## Notas

Los archivos grandes pueden estar truncados por límites de la API.  
El proyecto completo de Bird_Flight está disponible en el archivo `Bird_Flight_completo.tar.gz` (descárgalo desde el chat o artifacts).
